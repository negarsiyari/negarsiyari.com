# negarsiyari.com

Source code for my personal website: https://negarsiyari.com

The site presents my work in applied linguistics, newcomer education, AI literacy, teaching, and research.

## Development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

## Deployment

The site is deployed from the `main` branch with Cloudflare Workers.
